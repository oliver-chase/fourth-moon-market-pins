How to Host a Friendsmas Party

How to plan a Friendsmas party: pick a format, set a gift price limit, split the food and send the invitation on time.

Friendsmas is flexible, so the first job is to choose a format. Then set the rules that need setting, such as the price of a gift, and let the rest stay loose.

Pick a format

FormatBest forWhat to tell guests
Potluck dinnerA group of 8 to 20The dish category each person brings
Hosted dinnerA small groupDietary needs by the reply date
Gift swapFriends who like gamesThe price limit and the swap rules
Drop-in nightA busy monthA window of hours, such as 5:00 to 9:00 pm

Gift swap rules

  • Set one price limit and write it on the invitation.
  • For Secret Santa, draw names two to three weeks ahead and send each person their match.
  • For a white elephant swap, bring a wrapped gift, draw numbers, and let each player pick or steal in order.
  • Agree on a steal limit before you start, so the game ends.

Food

  • Ask guests to sign up for a category: main, side, dessert or drinks.
  • Collect allergy notes with the reply.
  • Set out labels for each dish.

Timeline

  • 4 to 6 weeks before: pick the date and send the invitation
  • 2 to 3 weeks before: draw names for a gift swap
  • 1 week before: send a reminder with the address and the dish list
  • Day of: set out plates, a drink station and a place for coats

Common questions

How do I run a white elephant gift swap?

Each guest brings one wrapped gift. Players draw numbers and, in order, either open a new gift or steal one that was already opened. Set a limit on steals so the game ends.

What price limit should I choose?

Pick a number that every guest can afford, and write it on the invitation.
